# Contact Application

A command line **Python spplication** to manage and search the contacts from list.

## Features
* **Dual Search Method** Can search for record by using contact name or contact number.
* **Full CRUD Operations** view, add, delete and search through a clean CLI terminal menu.

## Data Structure
* **Dictionary (`dic`):** used to store contact's name and number as a single entity.
* **List (`list`):** used to store each contact as one element, allowing by using index.

## How to Run
1. Make sure you have **Python 3.x** installed.
2. Download or clone `contact.py`.
3. Open your terminal, navigate to the folder, and run:
   ```bash
   python contact.py
   ```
