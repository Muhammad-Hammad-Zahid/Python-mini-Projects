# Student grade managment Application

A command line **Python spplication** to manage, find average and rank the highest and lowest scorer in each subject.

## Features
* **Multiple Subjects** Students can take same but multiple subjects.
* **Average Calculation** can calculate each subject average and store them in seperte list.
* **Find the Highest/Lowest grades** can find the highest scorrer and lowest scorer in each subject.

## Data Structure
* **Dictionary (`dic`):** used to store each student relevent data under the name and to store subject
* **List (`list`):** used to store each contact as one element, allowing by using index.

## How to Run
1. Make sure you have **Python 3.x** installed.
2. Download or clone `To_Do.py`.
3. Open your terminal, navigate to the folder, and run:
   ```bash
   python To_Do.py
   ```
